# Primitive DB

Примитивная база данных на Python с интерфейсом командной строки.

## Технологии

- Python 3.12+
- uv — управление проектом и зависимостями
- prompt — пользовательский ввод
- shlex — разбор команд
- JSON — хранение метаданных
- Ruff — проверка и форматирование кода

## Установка для разработки

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd primitive-db
uv sync
```

## Запуск

```bash
uv run database
```

## Доступные команды

| Команда | Назначение |
|---|---|
| `create_table users name:str age:int` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table users` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Завершить работу |

Поддерживаемые типы столбцов: `int`, `str`, `bool`.

Столбец `ID:int` добавляется автоматически при создании таблицы.

Метаданные таблиц сохраняются в JSON-файле `db_meta.json`.
