# Primitive DB

Примитивная база данных на Python с интерфейсом командной строки.

## Технологии

- Python 3.12+
- uv — управление проектом и зависимостями
- prompt — пользовательский ввод
- shlex — разбор команд
- JSON — хранение метаданных
- Ruff — проверка и форматирование кода

## Установка для разработки

Клонируйте репозиторий:

```bash
git clone https://github.com/mayerife/project-2_kravchenko_M26-555
cd project-2_kravchenko_M26-555
```

Установите зависимости:

```bash
uv sync
```

## Запуск

Для запуска базы данных в режиме разработки выполните:

```bash
uv run database
```

## Управление таблицами

База данных поддерживает следующие команды:

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список всех таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Показать справочную информацию |
| `exit` | Завершить работу программы |

### Создание таблицы

Для создания таблицы укажите её имя и столбцы с типами данных:

```text
create_table users name:str age:int active:bool
```

Столбец `ID:int` добавляется автоматически в начало структуры таблицы.

Поддерживаемые типы данных:

- `int` — целое число;
- `str` — строка;
- `bool` — логическое значение.

### Просмотр таблиц

Для просмотра списка существующих таблиц используйте:

```text
list_tables
```

### Удаление таблицы

Для удаления таблицы укажите её имя:

```text
drop_table users
```

### Пример использования

```text
Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int

Введите команду: list_tables
- users

Введите команду: drop_table users
Таблица "users" успешно удалена.

Введите команду: list_tables
Таблиц пока нет.

Введите команду: exit
Выход из программы.
```

## Хранение метаданных

Информация об именах таблиц и структуре их столбцов сохраняется в JSON-файле `db_meta.json`.

Если файл метаданных отсутствует, база данных начинает работу с пустым словарём.

## Сборка и установка пакета

Соберите пакет:

```bash
uv build
```

Установите собранный пакет:

```bash
uv tool install --force dist/*.whl
```

После установки базу данных можно запустить из терминала командой:

```bash
database
```
